# PetCard Promotional Website

Next.js App Router starter inspired by the provided DogCat.app promotional reference, redesigned for PetCard with an orange/cream visual direction.

## Pages
- /
- /features
- /how-it-works
- /about
- /faq
- /contact
- /auth
- /privacy
- /terms

## Run
```bash
npm install
npm run dev
```

This starter intentionally uses CSS phone/app mockups and placeholders instead of copying competitor artwork. Replace the mockups with the real PetCard app screenshots and approved brand/content once available.

## Important
- Contact details are placeholders.
- Statistics are intentionally non-factual promotional placeholders and should be replaced/removed before production.
- Privacy Policy and Terms are placeholders and need approved legal content.
- Authentication is UI-only; connect your backend/API for real login/signup/OTP.
